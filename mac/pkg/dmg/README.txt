Meltype のインストール

1. 「@PKG@」をダブルクリックします。
2. インストーラーが開いたら、案内に従って進めます。
3. メニューバーの入力メニューで Meltype for Mac を選びます。出ていないときは、いったんログアウトしてログインし直してください。
   それでも出ないときは、システム設定 → キーボード → 入力ソース →「編集…」→「+」→ 日本語 → Meltype for Mac を追加します。

■ 「開発元が未確認のため開けません」「開いていません」などと出て開けないとき

この pkg は Apple の署名・公証を受けていないため、最初に 1 回だけ許可が必要です。

macOS 15 以降:
  1. 一度ダブルクリックして開こうとし、出た表示を閉じる (「ゴミ箱に入れる」は押さない)
  2. システム設定 → プライバシーとセキュリティ
  3. 下のほうの「このまま開く」を押す
     (ログインパスワードを聞かれることがあります。
      「このまま開く」は、開こうとしてから約 1 時間だけ押せます)
  4. 確認の表示が出たら、開くほうを選ぶ
macOS 14 以前:
  pkg を右クリック (control + クリック) →「開く」→「開く」

心配なときは、リリースページ (https://github.com/whitewater-png/Meltype-for-Mac/releases) の SHA-256 と比べてから開いてください。
ターミナルで「shasum -a 256 」(最後に空白) と打ち、dmg のウインドウ (Finder) にある @PKG@ をターミナルへドラッグして Return を押すと表示されます。
