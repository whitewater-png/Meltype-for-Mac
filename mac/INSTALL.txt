Meltype for Mac インストールの手引き (テスト版)

※ 試作のため、動かないところがあります。気づいたことは GitHub の Issues から教えてください
   (https://github.com/whitewater-png/Meltype-for-Mac/issues)。
※ 更新は個人の気ままな対応です。ご連絡いただければ幸いです。
※ 機能の一覧・詳しい使い方は、GitHub のリポジトリの README を見てください
   (https://github.com/whitewater-png/Meltype-for-Mac)。このファイルは、zip を受け取った人向けの要点だけです。

Meltype はアプリではなく「入力ソース」(日本語入力) です。Meltype.app をダブルクリックしても何も起きません。
下の手順でインストールして、入力ソースに追加して使います。

■ 動く環境
  macOS 13 以降、Apple シリコン (M1 / M2 / M3 / M4 …) の Mac

■ インストール
  1. この zip を展開する
  2. 「Install Meltype.command」をダブルクリック
       「開発元が未確認のため開けません」と出たら、右クリック (control + クリック) →「開く」→「開く」
       (macOS 15 以降は、一度ダブルクリックしてから システム設定 → プライバシーとセキュリティ →
        下のほうの「このまま開く」を押す)
       (それでも開けないときは、「ターミナル」を開いて次の 1 行を貼り付けて Enter:
          bash ~/Downloads/Meltype-mac/install.sh  )
  3. メニューバーの入力メニューで Meltype を選ぶ
       (入力メニューに出ていないときは、いったんログアウトしてログインし直す。それでも出ていなければ、
        システム設定 → キーボード → 入力ソース →「編集…」→「+」→ 日本語 → Meltype を追加)
  ※ 新しいテスト版に入れ替えるときも、同じように「Install Meltype.command」をダブルクリックします。
    ~/Library/Input Methods の Meltype.app を自分で消してから入れ直すと、ログアウトするまで Meltype が使えなくなります。

■ インストール前の確認 (SHA-256) と、インストールがすること
  ・この zip は Apple の公証を受けていません。受け取った zip が本物か、ターミナルで次を実行し、
    リリースページ (または渡した人) が載せた値と同じか見比べてください
       shasum -a 256 ~/Downloads/Meltype-mac.zip
    (ファイル名は実際のものに合わせる。1 文字でも違えば、使わないで知らせてください)
  ・インストール (install.sh) は、はじめに Meltype.app の署名が壊れていないか確かめ (壊れていたら中止)、
    実行ファイル (IME と辞書の管理画面) と libMeltypeNative.dylib の SHA-256 を表示します。これもリリースページの値と見比べられます
  ・install.sh がやること (これ以外には触れません。管理者権限・ネットワーク通信は使いません)
      - ~/Library/Input Methods/Meltype.app に入れる (入れ直しのときは rsync で中身だけ入れ替え、動いている Meltype と、
        開いている辞書の管理画面「Meltype 辞書」を止める。辞書の変更はその都度保存済みなので消えません)
      - 入力ソースとして登録し、入力メニューと IME の起動役を起動し直す (killall imklaunchagent TextInputMenuAgent)
      - 登録できないときだけ、入力ソースの一覧に書き込む (defaults write com.apple.HIToolbox AppleEnabledInputSources)
      - 「インターネットから取得した」印 (隔離属性) を外す: macOS の Gatekeeper の検査を、この Meltype.app について回避します。
        テスト版は公証を受けていないので外さないと起動しません。ターミナルでは「外しますか? [y/N]」と聞きます
        (SHA-256 が一致するときだけ y)。聞かずに進めるなら  bash install.sh --yes

■ 新しい版の通知と更新 (通信について)
  ・Meltype は打った内容をネットワークに送りません。通信するのは、新しい版の確認だけです
  ・既定で 1 日 1 回、GitHub の最新 Release の情報を取得します (送るのは取得の要求だけ。GitHub には IP アドレスと Meltype の版が見えます)
  ・止めるには、メニューバーの入力メニュー →「更新を確認する」のチェックを外します (「今すぐ更新を確認する」を押したときだけ通信します)
  ・新しい版があると、入力メニューに「新しい版があります…」が出ます。更新は、これを選んで「更新する」を押したときだけ行います
    (zip をダウンロードし、SHA-256・zip の中身・署名の封印を確かめてから、install.sh --yes で入れ替えます。自動では入れません)
  ・入れ替えに失敗したときは、入れ替え前に退避した元の Meltype に戻します
  ・「更新する」が出るのは、Meltype が ~/Library/Input Methods/Meltype.app にあるときだけです
  ・電子署名は付いていないので、GitHub のアカウントが乗っ取られた場合は防げません (SECURITY.md)

■ 使い方 (要点。詳しくは README)
  ・ふつうにローマ字で打つと日本語、英単語 (google、github …) は英字のまま
  ・Space で変換、Enter で確定、← → で文節を選ぶ、Esc で取り消し
  ・変換したあとに続けて打っても確定しない設定: 入力メニュー →「変換後も続けて入力できる」(既定は OFF)
  ・F6 ひらがな / F7 カタカナ / F8 半角カナ / F9 全角英数 / F10 半角英数
    (F キーが効かないときは、変換中に Ctrl+J / K / ; / L / ' でも同じ)
  ・JIS キーボードの「英数」「かな」キー、または Caps Lock で、英数と日本語を切り替え
  ・予測変換は Tab、候補は数字キー 1〜9 で選べます
  ・ユーザー辞書・専門用語集の管理: 入力メニュー →「辞書を管理…」で「Meltype 辞書」の画面が開きます
    (一覧・検索・登録・編集・削除。削除は ⌘Z で元に戻せます。専門用語集は分野の ON/OFF と、語ごとの「除外」「直す」)
    画面での変更は、動いている Meltype にすぐ反映されます

■ 不具合を報告するとき
  ・単語だけでなく、文章で試してください。Meltype は文章の前後の流れから推論して変換します。
    例: 単語だけ「hosuthingu」→「ほすthinぐ」。文章の中で打つ (「パソコンのホスティング」と打つ) と「パソコンのホスティング」
    文章にしても直らないときが不具合です。その文章を報告してください
  ・どのアプリで、何と打って、どうなったか (できればスクリーンショットも)
  ・動きがおかしいときのログ: ターミナルで次を実行してから操作すると、ログが流れます
       log stream --predicate 'process == "Meltype"' --level debug

■ 止まってしまったら
  ターミナルで  pkill -x Meltype  (次にキーを打つと自動で起動し直します)

■ 学習データの消去
  入力メニュー (メニューバーの Meltype) →「学習データをすべて消去…」で、変換・予測の学習などを消せます
  (ユーザー辞書と設定は消えません)。保存した学習データは、あなたのアカウントだけが読める権限 (0600) で置かれます。

■ パスワード欄
  macOS が「秘匿入力」にしている入力欄 (パスワード欄など) では、Meltype はキーを扱わずアプリに素通しします。
  ただし、アプリが macOS に秘匿入力と知らせていない欄は検知できません。確認できていない欄では、念のため英数にしてください。

■ アンインストール
  1. zip の中の「Uninstall Meltype.command」をダブルクリック (開けないときは右クリック →「開く」)
       ターミナルなら:  bash ~/Downloads/Meltype-mac/uninstall.sh
     → 入力ソースを外して Meltype.app を削除します (中の辞書の管理画面「Meltype 辞書」も一緒に消えます)。
       設定・学習データ・ユーザー辞書を消すかどうかは、聞かれたときに選べます
       (消すときは、ユーザー辞書をデスクトップにバックアップしてから消します)
  2. いったんログアウトしてログインし直す (入力メニューから完全に消えます)
  手で消すとき: システム設定 → キーボード → 入力ソース →「編集…」で Meltype を外してから、ターミナルで
       rm -rf ~/Library/Input\ Methods/Meltype.app
     設定と学習データも消すなら
       rm -rf ~/Library/Application\ Support/Meltype
  (消したあとにもう一度インストールするときは、先にログアウトしてログインし直してください)
