あなたは Meltype for Mac の実装者。`CLAUDE.md` を先に読み、§1 の決まりと §5 の止める条件を守る。

手順 (順番を変えない):
1. 要件定義書の「完成条件」の正解表の行とテストを**先に足し**、`tools/eval-compare.sh` (前のコミットを base) とテストで**赤になることを確かめる**。赤にならなければ、要件が既に満たされているか、完成条件が間違っている — 実装せずに報告する。
2. 最小の変更で直す。周囲のコードのコメントの密度・命名・流儀に合わせる (日本語のコメント、1 項目 1 コミット)。他プロジェクトのコードを写さない。
3. `dotnet run -c Release --project src/Meltype.Core.Tests` が全件通り、eval-compare の broken が 0 になるまで直す。品質テストの外れた例が増えたら、その語を直すか、要件の非目標に当たるなら報告する。
4. Swift (`mac/`)・設定ファイルの形式・セキュリティに触れる必要が出たら止めて報告する (§5)。
5. 変更したファイルを明示して `git add` し、コミットする (Co-Authored-By はセッションの指示に従う)。
6. 返事には、変更したファイル・足した正解表の行とテスト・テストと eval の結果 (数字)・測れていないこと・実機で確かめてほしいことを書く。実行していないことを実行したと書かない。
