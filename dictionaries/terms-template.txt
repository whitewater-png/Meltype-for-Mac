# ライセンス: (例: 自作 (GPL-3.0-or-later で提供) / CC BY 4.0 など。ATOK・Microsoft IME・Google 日本語入力などの辞書の内容は写さないこと)
#
# 形式: 1 行に「読み<Tab>語<Tab>注記(任意)」。区切りは Tab (スペースではない)。# で始まる行と空行はコメント。
#   - 読みはひらがな (長音「ー」は可。数字・英字・中点「・」は不可)。2 文字以上 100 文字以下。
#   - 語は 100 文字以下。改行・Tab は使えない。
#   - 注記 (3 つ目の欄) は読まれない。メモに使える。
#   - 同じ読みに複数の語があるときは、行を分けて書く (先に書いた語が先に出る)。
#
# 読みの短い語について: 読みが 4 文字以上の語は「強制型」(変換する文の中にその読みがあれば、その部分を語にする)、
# 3 文字以下の語は「候補追加型」(変換候補に足すだけ。日常語の途中に混ざって誤変換にならないよう、強制しない)。
#
