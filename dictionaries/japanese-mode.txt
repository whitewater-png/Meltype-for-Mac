# 日本語の入力中に、英字ではなくかなとして変換する語 (本家 #1023)
#
# 設定「日本語入力中は一覧の語をかなで変換する」(Settings.KanaInJapaneseMode) を ON にしたときだけ効く。
# 英語の辞書 (english.txt) にある語でも、ここに書いた語は日本語の文脈 (前が英語でない) でかなとして扱う。
# 英語の文の中 (前が英単語) と、ファイルの拡張子 (.exe / foo.exe) は今までどおり英字のまま。
# 英数 (直接入力) では変換ボックスを通らないので、ここに関係なく英字で入る。
#
# 例: exe → 日本語の文脈では「えぇ」、英語の文脈では「exe」。
# 1 行に 1 語 (空白・カンマ区切りも可)。# から行末まではコメント。
