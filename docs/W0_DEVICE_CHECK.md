# W0-3 実機確認チェックリスト (macOS 26.6.2 / JIS)

所要 5〜10 分 (準備 2 分 + 4 項目)。対象は HEAD `42443be` のビルド。

**失敗したら渡してほしいもの**

1. **打った > 結果** (例: `こうしょう > PageDown で 10 個目が見えない`、`exe > えぇ`)
2. **スクリーンショット** (メニューバー / 候補ウィンドウ / ダイアログ。時刻が分かるもの)
3. **ログ**: `~/Library/Application Support/Meltype/meltype.log` (設定の「ログ」→「ファイルにログを書く」が ON のときだけ)
4. アプリ名 (TextEdit / Chrome など) と Meltype の版

**禁止**: 更新ダイアログの「更新する」は押さない (公開行為になる)。「あとで」で閉じる。

## 0. 準備 (2 分)

- 日本語モードにする (入力メニュー、または JIS のかなキー)。
- TextEdit: 新規書類 (標準テキスト)。Chrome: スクロールする長いページ (Wikipedia など) と入力欄。
- PageUp/PageDown は、ノート型は `fn+↑` / `fn+↓`。F10 は「F1、F2 などのキーを標準のファンクションキーとして使用」が OFF なら `fn+F10`。
- スクショ: `⌘⇧4`。メニューを開いたまま撮るときは `screencapture -T 5 -R 0,0,1000,300 ~/Desktop/menu.png` を実行して 5 秒以内にメニューを開く。

## 4. 入力ソースのアイコン

前提: 日本語 = `icon.tiff`、英数 = `icon-roman.tiff` (`Info.plist:71-74, 100-103`)。どちらも 16×16@72 + 32×32@144 の 2 表現、`TISIconIsTemplate` は false (カラー)。
実測の墨の範囲: `icon` の 2x は 32×30/32 (ほぼ全幅)、`icon-roman` の 2x は 26×32。

| # | 操作 | 期待 | 記録 |
| --- | --- | --- | --- |
| 4-1 | 日本語モードでメニューバーを見る | 他のアイコンと極端に違わない大きさ、上下にずれない、氷の M が読める | `大きさ: 大／小／同じ / 上下: ずれ／同じ` |
| 4-2 | 入力メニューの一覧で Meltype の行を見る | 行の高さに対して大きすぎ・小さすぎがない | `一覧: ____` |
| 4-3 | 英数キー → かなキー | M → A → M と切り替わる。大きさが揃って見える | `切替: ○× / 大きさ: 揃う／Mが大／Aが小` |
| 4-4 | Blue などの入力欄でカーソル付近の入力ソース表示を見る | 出る。にじみ・欠けがない | `出る／出ない / ____` |

疑う場所: `mac/Resources/Info.plist:47-51` (`tsInputMethodIconFileKey`・`TISIconIsTemplate`)、`mac/Resources/icon*.tiff`。

`docs/KNOWN_LIMITS.md:90` (K46): macOS 26 では候補ウィンドウ横のモード表示が出ないため、**モードはメニューバーのアイコンで見る**しかない。
