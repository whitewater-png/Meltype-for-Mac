# 既知の制限の仕分け表 (施策 0-5)

開発者・メンテナー向けの正本です。利用者向けには、`README.md` の「制限 (知っておいてほしいこと)」に、ここの「仕様」と「直す予定」のうち遭遇しやすいものだけを短く載せています。
対象は Mac 版だけです (Windows / Linux は対象外)。「本家 Meltype」は Windows 版の本家を指します。

- 出発点: 2026-10-13 時点の棚卸し (計画書の各節に散らばった制限)。その後に増えた P45・0-2・0-4 の節も拾って、2026-10-14 に仕分けました。
- 「打鍵 → 今の結果」は、`--repro` (Core のテスト用キーボード。変換エンジンは偽物なので漢字にはならず、日英の判定とかなだけを見る。同梱の英単語表を使い、実機の NSSpellChecker とは答えが違うことがある) で 2026-10-14 に取ったものです。実機で見たものではありません。実機で確かめた記録があるものは、根拠の欄に日付を書きました。
- 「BI」「NS」(K87〜K89 など): `--repro` の **BI** は同梱の英単語表で判定する再現、**NS** は実機の NSSpellChecker の答えを差し込んだ再現です。どちらも実機そのものではありません。
