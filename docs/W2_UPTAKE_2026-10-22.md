## 本家の症状と、うちの直し方

本家 #1008 は `1000Hz.` と打つと `1000H…` になる (z 変換が勝手に `…` にする)。`z` 変換自体は便利なので、**設定で切れるようにする**のが本家の提案で、我々も同じ形にした。

ただし単純に「記号を変換しない」だけだと、OFF でも `jazz.` の `zz` が `じゃっ` に読まれたまま残る。そこで OFF では:

1. **直前の英字の並びが知っている英単語のとき** (`jazz`・`1000hz`・`10oz`・`quartz`、数字 + 2 文字以内の単位) は、打った綴りの英字に戻して記号を足す。
2. **英単語にならない英字** (`かぞえかた` + `z`) は、記号と合わせて **1 つの単位** (`Kana = Raw = "z."`) にする。`Raw` に記号が入るので英字の並びの走査から外れ、確定前の打ち間違いの直し (`kazoekataz` → `kazoekata`) が**構造的に**触らない。
3. 日本語 (きょう・ずっと・にほんご・かぞえかた) は**かなのまま**残す。

## 途中で捨てた案と、その理由

| 案 | 捨てた理由 |
| --- | --- |
| `--repro` を環境変数 `MELTYPE_REPRO_ZOFF` で切り替える | `--repro` は bot も使う。環境変数で挙動が変わると事故る |
| 「打ったまま足した英字」に一時的な印 (`_typedTail`) を付ける | 印が**次の打鍵で消える**ため、`kazoekataz.desu` で `z` が落ちた (`かぞえかた.です`)。印ではなく単位の形で守る |
| OFF のすべてを記号込みの 1 単位にする | `zuttojazz.` が `ずっとじゃz.` になり、`jazz.` のあとの Space が英語として扱われない。英単語は英字 1 文字ずつに戻す形を残した |
| 直前の英字を無条件に打った綴りへ戻す | `kyouz.` が `kyouz.` になり、日本語が英字に戻った |

## 実機で見ること (`docs/DEVICE_CHECK_2026-10-22.md` の W2-1)

1. 設定タブ →「入力」→「z + 記号を変換する」を**オン**のまま: `kyouz.` → `きょう…`、`1000hz.` → `1000h…`、`jazz.` → `じゃっ…` (今までどおり)
2. **オフ**にして: `kyouz.` → `きょうz.`、`kazoekataz.desu` → `かぞえかたz.です`、`1000hz.` → `1000hz.`、`jazz.` → `jazz.`、`10oz.` → `10oz.`、`z-axis` → `z-axis`
3. オフのまま `zh` `zj` `zk` `zl` → ← ↓ ↑ → (`zebra`・`z` がそのまま)
4. 設定を切り替えた**直後の 1 打目**から変わる (アプリの再起動は不要)
5. どちらでも BackSpace 1 回で `.` だけ消える
