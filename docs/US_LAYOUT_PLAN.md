# US 配列対応 要件定義・作業計画書

ブランチ: `feat/us-layout-support` (`main` から分岐。かな入力の `feat/mac-kana-input` とは分けている)

## 1. 背景と目的

- MacBook 利用者には US 配列のユーザーが多くいる。
- 現状の Mac 版は、実機確認がすべて JIS 配列 (`docs/IMPROVEMENT_PLAN.md`)。
- 目的は、US 配列でもローマ字入力が JIS と同じ品質で動くようにすること。US で使えない機能は、誤って使われないよう案内する。

## 2. 現状 (コードを読んだ範囲。実機では未確認)

| 項目 | 結果 |
|---|---|
| 文字キー (a〜z・0〜9)、`, . - / [ ]` | 打った文字で判定する (`KeyMapping.swift`) ので、US でも同じ動作の見込み |
| `;` `'` | 物理キーの位置で判定。US を意識した実装 (US の Ctrl+`'` が半角英数) |
| 英数への切り替え | US は Caps Lock か入力メニュー (Caps Lock は実機未検証) |
| `\` の扱い | **疑い**。`CompositionText.Symbol` が `\` を全角の `￥` に変換する (962〜963 行目)。US では `\` キーなので意図と合わない可能性がある |
| かな入力 | JIS 専用。US で選ぶと記号キーの位置がずれる |
| テスト | 擬似ホストの記号表 (`FakeHost.JisKeys`) が JIS のみ。US のテストがない |

## 3. 決定事項

| 論点 | 決定 |
|---|---|
| `\` の方針 | **案 A**: 日本語入力中でも常に半角の `\` にする。まず JIS 実機で影響を確認してから採否を確定する |
| かな入力の US 対応 | 案内を出すだけ (S1)。US 向けのかな配列は作らない |
| ブランチ | `feat/us-layout-support` |
| 保存先 | `docs/US_LAYOUT_PLAN.md` |

## 4. 要件

**必須**

- M1. US 配列で、ローマ字入力と英語・日本語の自動判定が JIS と同じ結果になる。
- M2. US 配列で `\` を打つと、日本語入力中でも半角の `\` が入る。
- M3. US 配列の記号キー全般 (`` ` ~ ! @ # $ % ^ & * ( ) _ + = { } | : " < > ? ``) が期待どおりに入力・確定される。
- M4. JIS 配列の現在の動作を変えない。
- M5. 変更をテストで固定する。

**推奨**

- S1. かな入力を US で選んだとき、説明文などで案内する。
- S2. `README.md`・`mac/README.md`・`docs/USAGE.md` に、US 配列の使い方と制約を書く。

**対象外**

- US 向けのかな入力、Windows・Linux 版の US 対応、英数を切り替える新しいキーの追加。

## 6. 受け入れ条件

1. Core のテストが全件通り、US 配列のテストが追加されている。
2. US で `\` を打つと、日本語入力中でも `\` が入る。
3. JIS の既存テストが変わらず通る。
4. `swift build` が成功する。
5. 実機チェックリストが用意されている。

**実機チェック項目 (US)**

- ローマ字入力で日本語が打てる。
- `\ | ` ~ @ # $ ^ & *` が入力できる。
- Ctrl+`'` で半角英数に切り替わる。
- Caps Lock で英数に切り替わる。

**実機チェック項目 (JIS・案 A の影響確認)**

- ¥ キーと Option+¥ で、期待どおりの文字が入る。

## 7. リスク・注意

- **S1 の依存関係。** 設定画面の「入力方式」と説明文は、かな入力のブランチ (`feat/mac-kana-input`) にしかない。`main` から分けたこのブランチでは、S1 を設定画面で行えない。
  - 対処案 1: S1 は、かな入力のブランチが `main` に入った後に追加する。このブランチでは、ドキュメント (S2) への記載にとどめる。
  - 対処案 2: かな入力のブランチをコミットして、そこから分岐する。
  - 着手時にどちらにするか決める。
- **案 A の影響。** JIS で `\` を打つ人の挙動が変わる可能性がある。工程 1 の調査と JIS 実機の確認で、採否を確定する。
- **実機。** US 配列の実機は手元にない前提。Caps Lock 切替は JIS でも未検証。
- **競合。** 別セッションが `CompositionText.cs` などを触っていると衝突する。着手前に確認する。
