# 032 ユーザー辞書の語を「文節の途中からも使う」しきい値を、文字数でなく拍数で数える

## 背景 (誰が、何に困っているか)
- 実機で `gakushuusuru` + Space (「学習する」を打つ) と、「がく週する」になる。実機のトレースでは、Space の直後の文節が `がく|週|する` の 3 つに分かれていた。変換エンジン単体では `がくしゅうする` は「学習する」の 1 文節になる (この点は、リョウさんの調査で確かめ済みと聞いている。Core のテストでは、同じ区切りを返す偽のエンジンで再現した)。
- 実機のユーザー辞書には、読み「しゅう」の登録語 (例: しゅう → 珠佑。人名と思われる) がある。さらに、Core の学習データ (`conversions.json`) に しゅう → 週 (確定回数 8) がある。
- 今の挙動 (Core のテストで再現。実機では未確認): ユーザー辞書に しゅう → 珠佑、学習データに しゅう → 週 があるとき、エンジンが `がくしゅうする` を 1 文節で返しても、`がく|週|する` になる。

## 今の動き (既に分かっていること)
- 関係する場所: `src/Meltype.Core/Composition/CompositionController.cs` の `InsideClauseMinReadingLength` (定数 3) と `AlignUserWords`。ユーザー辞書の語は、読みが 3 文字以上なら、エンジンの文節の途中から始まっても使う (読みが短い語だけ、文節の頭から始まるときに限る。本家 #374・PR #385 の しの → 紫乃 の対策。3 文字以上の名前 (さくら・ひなた・ゆうき) が助詞の後ろで落ちないよう、しきい値は 3 と決めてある。`docs/IMPROVEMENT_PLAN.md` P30b)。
- 原因: 「しゅう」は音では 2 拍 (しゅ・う) だが、文字では 3 文字 (し・ゅ・う)。文字数で数えるので「長い語」と扱われ、`がくしゅうする` の途中に割り込む。割り込んだ語は学習の しゅう → 週 の対象になり、`週` と表示される。「しゅう」「じゅう」「しょう」のような音はどんな語の途中にも現れやすく、しきい値を決めたときの「短い語は偶然現れやすい」という理由が、2 拍の語にも当てはまる。
- しきい値 (`InsideClauseMinReadingLength`) を使う場所は、`CompositionController.cs` の `AlignUserWords` の 2 か所 (途中から始まる短い語があるかの検査と、使う語を決める判定) だけ。ほかは説明のコメント (`UserDictionary.cs` の冒頭)。`rg InsideClauseMinReadingLength` で確かめた。
- 本家 (yksr-melt/Meltype) の扱い: 本家に無い (この仕組みは Mac 版が P30b で足したもの)。

## minimum の要件 (これだけは満たす)
1. 「文節の途中から始まっても使う」ユーザー辞書の語の判定を、読みの文字数でなく拍数で行う。拍数 = 読みの文字数から、直前の文字といっしょに 1 拍と数える小さいかな (ゃゅょぁぃぅぇぉ。拗音と外来語の小さい母音) を引いたもの。っ・ん・長音 (ー) は 1 拍のまま。しきい値の値 (3) は変えない。
2. 判定の規則は小さなメソッド 1 つ (`CompositionController.UserWordMoraCount`) にまとめ、`AlignUserWords` の 2 か所が同じメソッドを使う。得と損をコメントに書く。
3. 文節の頭から始まるときの扱い (`starts.Contains(position)`) は今までどおり。拍数 3 以上の名前 (さくら・ひなた・ゆうき・じゅんすけ・ふぁいる・ちゃんと) は、途中からでも今までどおり使う。
4. 新しい設定項目は作らない。学習データ・ユーザー辞書のファイルは書き換えない。

## 非目標 (今回はやらない)
- 学習データ (`conversions.json`) の しゅう → 週 を直す・消すこと (データの書き換えは人の判断。人の判断 3)。
- ユーザー辞書の登録語を消す・読みを変えること。
- しきい値 (3) を変えること、拍の数え方を小さいかな以外 (長音・促音・撥音の特別扱い、「ゎ」など) に広げること。
- 設定画面・Swift (`mac/`) の変更。

## 人の判断 (ユーザー辞書の語の使われ方が変わるので、人が決める)
1. **拍数で数える変更を入れるか。**
   - 案 A (推奨): 拍数で数える。しゅう・じゅう・しょう のような音が語の途中に現れやすいことによる誤変換を防ぐ。**損**: 拗音を含む 3 文字の名前 (じゅん・しゅう など) は、エンジンの文節の途中から始まるときは使われなくなる (文節の頭から始まるときは今までどおり。使いたいときは文節の区切りを Shift+←→ で変えれば候補から選べる)。実機のユーザー辞書のコピー (18 語) では、この損を受ける語は **1 語** (しゅう を除く 17 語のうち)。
   - 案 B: 入れない。しゅう の登録語を持つ人は、同じ誤変換が起き続ける (登録語を消すか読みを変えるしかない)。
   - 案 C: しきい値を 4 にする。さくら・ひなた・ゆうき が助詞の後ろで落ちる (P30b の実測)。推奨しない。
   - 決めないままだと: 案 B と同じ (今の実機の「がく週する」が続く)。
2. 小さいかなの範囲を、ゃゅょぁぃぅぇぉ にしてよいか (っ・ん・ー は 1 拍、「ゎ」は数えない)。広げる必要が実機の辞書では見つからなかった。推奨: このまま。
3. 学習データの しゅう → 週 (確定 8 回) はそのまま残す (この要件では消さない)。しゅう だけを変換したときの学習は今までどおり。推奨: そのまま。
