# 006 計算の候補で ^ (べき乗) を読む

## 背景 (誰が、何に困っているか)
- 本家 #1403 の提案 (対象 OS「すべて」): 四則演算は結果が候補に出るが、`2^10` のようなべき乗は出ず、`2*2*2*…` と書き下すしかない。巨大な数 (`5^20` など) で固まったり表示が崩れたりしないよう、上限も設けてほしい。
- 今の挙動 (Core): 設定「計算式を変換すると結果を候補に出す」が ON でも、`Calculator.Evaluate("2^10")` は null (`^` を読まない)。

## 今の動き (既に分かっていること)
- 関係する場所: `src/Meltype.Core/Composition/Calculator.cs` (式を自前で読む。`+ - * / ( )` だけ)、呼ぶのは `CompositionController` の Space の経路 (設定 ON・ローマ字入力・自動モードのときだけ)。
- 上限: 式は 80 文字まで、結果の絶対値が 1e15 以上なら出さない。
- 設定の説明文: `src/Meltype.Core/Config/Settings.cs` と `MacSettingsCatalog.cs` が「数字と + - * / ( ) だけの式」と書いている。
- 本家の扱い: #1403 は open・未対応 (2026-11-01 時点)。

## minimum の要件 (これだけは満たす)
1. `2^10`・`2^10=`・`(1+1)^3`・`２＾１０` (全角) で結果が出る。`^` は右結合 (`2^3^2` = `2^(3^2)` = 512)、`*` `/` より先、単項の `-` より先 (`-2^2` = -4、`2^-1` = 0.5)。
2. 上限を守る: 途中の値でも絶対値が 1e15 以上になるべき乗、実数にならないべき乗 (`(-8)^0.5`)、無限大になるべき乗 (`0^-1`) は式全体を null にする。`5^25`・`10^100` で結果を出さず、固まらない。本家 #1403 の例 `5^20` (約 9.5e13) は上限の内側なので結果 `95367431640625` を出す。
3. `^` を含まない式の結果は今と同じ。`^^`・`^_^`・`3^`・`^3`・`2^^3` は null。

## 非目標 (今回はやらない)
- `**` 表記、関数 (`sqrt` など)、指数表記 (`1e5`)。
- Swift 側の変更 (設定の画面は Core の説明文を表示するだけ)。
