# 053 16 進のカラーコード (#30b0e8・#fff) を英字のまま確定する

## 背景 (誰が、何に困っているか)
- 本家 #2383 (Windows、Unity): `#30b0e8` が `#30b0え8` になる (Space では `#30b0絵8`)。CSS・デザインの道具で色を打てない。
- 今の挙動 (Core の `--repro`、2026-11-27 クラウド、origin/main `91fef24`):
  - `#30b0e8` → `#30b0え8`、`#ff00e8` → `#っf00え8`、`#e8e8e8` → `#え8え8え8`、`#30B0E8` → `#30B0え8`
  - `#fff` → `#っっf`、`#abc` → `#あbc`、`#30b0e8ff` → `#30b0え8っf`
  - `color: #30b0e8;` → `color: #30b0え8;`、`background: #ff00e8;` → `background: #っf00え8;`、`(#30b0e8)` → `(#30b0え8)`
  - 既に英字のまま: `#FFF`・`#bad`・`#beef`・`#dead`・`#face`・`#123`・`#12345`

## 今の動き (既に分かっていること)
- 関係する場所: `src/Meltype.Core/Composition/CompositionDetector.cs` の `ProtectedEnd` (保護区間 1-4a: パス・オプション・変数を、語の頭から英字のまま残す)。`#` + 16 進はどの保護区間にも当たらず、ローマ字として読める `e`・`ff`・`a` がかなになる。
- 正解表は `#` で始まる行を注釈として読み飛ばす (`eval/README.md`)。`#` で始まる入力は C# のテストで守り、正解表には前に語がある形 (`color: #30b0e8;`) を足す (要件 012 と同じ扱い)。
- 本家 (yksr-melt/Meltype) の扱い: PR #2392 で直した (報告による)。クラウドからは本家に届かないので、本家のコードは読まずに作る。

## minimum の要件 (これだけは満たす)
1. 語の頭 (入力の先頭・空白・開きの記号の後) の `#` に続く 16 進の 3・4・6・8 桁で、後ろが入力の終わりか英字・数字以外の記号 (`;` `,` `)` など) のものを、英字のまま確定する。
2. ただし、ハッシュタグや日本語と見分けられない形は今のまま:
   - 英字だけで、ローマ字として最後まで読める形 (`#abe` あべ・`#cafe` かふぇ・`#ace`・`#eee`) はかなのまま。
   - 数字の後ろに、ローマ字として最後まで読める英字だけが続く形 (`#1de` 1で・`#10ba` 10ば) はかなのまま。
   - 頭の っ も読める形に数える (`#fffa` っっふぁ・`#bba` っば・`#1ffa` 1っふぁ はかなのまま)。
   - 打っている途中 (語の後ろに空白も記号も無く、確定でもない) は、英字がローマ字の打ちかけとして読めるあいだはかなのまま (`#caf` → `#かf`。ハッシュタグ `#cafe` を打つ途中で英字にちらつかない)。`#fff` は打っている途中は `#っっf`、確定・空白・記号で `#fff`。
3. 6・8 桁の終わりの `de` は、2 桁短くてもカラーコードなら助詞の `で` として残す (`#30b0e8de` → `#30b0e8で`、`#beefde` → `#beefで` (今の形))。
4. `#` の後ろの日本語のハッシュタグ (`#nihongo`・`#ekimae`)、C の指令 (`#endif`・`#define` の今の形)、`C#`・`F#de` の今の形は変えない。

## 非目標 (今回はやらない)
- 日本語のすぐ後ろ (空白なし) の `#` (`kyouha#fff`)。保護区間と同じく、語の頭からだけ守る。
- 日本語 + 空白の後ろの `#` (`iro ha #30b0e8 desu` → `いろは#30b0え8です`)。区間分け (`--segments`) では英字の区間になるが、確定は今までどおり崩れる。既存の保護区間も同じ (`kyouha /tmp/foo` → `今日は/tmp/ふぉお`) で、この要件の前からの制限。
- カラーコードのすぐ後ろに日本語が続く形 (`#30b0e8wo`)。後ろが英字なので、今までどおり判定する。
- 英字だけで読めてしまう色 (`#eee`・`#aaa`・`#fffa` (っっふぁ)・`#cafe`)。ハッシュタグと見分けられないので、かなのまま。
- 打ち間違いの補正で今はかなになる、英字だけの 16 進の形 (`#cafd` → `#かふぇ`、`#acd` → `#あせ`、`#abca` → `#あんか`)。ローマ字としては読めないので、カラーコードとして英字のままになる (`(#` + 1〜5 桁の総当たり約 35 万入力のうち 65 件。受け入れる)。
- コロンの後ろに空白の無い CSS (`color:#30b0e8;` → `color:#30b0え8;`)。`:` の後ろは語の頭ではないので、今までどおり崩れる。
- カラーコードを打っている途中の表示 (`#30b0e` は `#30b0え`、`8` を打つと `#30b0e8`)。
- 5・7 桁や 9 桁以上の形、`0x` で始まる 16 進。
- 漢字の形 (Space の候補)。
