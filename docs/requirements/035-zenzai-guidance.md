# 035 Zenzai の案内を設定画面で強める

## 背景
- 2026-11-24 に「Zenzai は既定 OFF のまま。設定画面の案内を強めるかは別に決める」とした (AJIMEE_BENCH)。今日、リョウさんが「既定は OFF のまま、設定画面で ON を勧める」案を承認した。
- 根拠 (どちらも M4 Max。M1 級は未確認): AJIMEE 200 件の第一候補の一致 44.0% → 82.5% (OFF → ON)、比較ベンチのかな漢字 120 文で 86 → 105 文。変換は 1 文 p50 約 8 → 18 ms (比較ベンチ)。
- 今までの文は「文脈に合う漢字が先頭に来やすくなります」で、何が良くなるか (同音異義語) と、引き換え (遅さ・古い Mac は未確認) が読み取れなかった。

## 実装で確かめたこと (文に書く前に読んだ)
- モデル: `ZenzaiModel.swift` の `Source`。Hugging Face の `Miwa-Keita/zenz-v3.1-small-gguf` の Q5_K_M、**73,871,968 バイト (約 74 MB)**、https のみ・転送先を制限、サイズと SHA-256 を固定。取得するのはモデルだけで、打った内容は送らない。
- 取得は設定を ON にしたとき 1 回だけ。終わるまでは今までどおりの変換。
- 遅さの安全弁: `Converter.swift` の `noteZenzaiRequest`。1 キーの変換 (予測・ライブ変換・文節候補の合計) が 0.3 秒を超えることが 3 キー続くと、その IME のプロセスでは Zenzai を使わない (設定は ON のまま。IME が起動し直されると戻る)。モデルを読み込めないときも同じ。
- 例の確認: 製品の変換経路 (`MeltypeIME --convert-eval`) で OFF / ON を比べた (M4 Max)。`きのうこうえんをきいた` は OFF 昨日**公演**を聞いた → ON 昨日**講演**を聞いた、`いしをひろった` は OFF **意志**を拾った → ON **石**を拾った、`このいしはおもい` は OFF この医師は思い → ON この**石は重い**。同じ入力でも OFF が当たる語もある (`こうえんでおはなしをきく` は両方 公園で…) ので、例は「ON で当たる」ことだけを言い、「OFF は必ず外れる」とは書かない (「OFF では 意志を拾った」は測った出力)。

## 変えたもの
1. `Settings.cs` の Zenzai の Description (Windows の設定画面にも反射で出る共通の文) は**変更前のまま**。Windows では Zenzai の速さを測っていないので、Mac 固有の案内は書かない (査読 R2 の指摘で戻した)。
2. `MacSettingsCatalog.cs`: 要約 (1 行)、例 (`いしをひろった → 石を拾った (OFF では 意志を拾った)`)、「詳しく」(MacDescription: 得・損 3 点・Hugging Face から取得・送るのはモデルの要求だけ・M4 Max でしか測っていない・安全弁・OFF でいつでも戻る)。
3. README (公開物) の特徴の行と `mac/README.md` の Zenzai の節を同じ内容に。README は「実験的、既定 OFF」を残し、数字は書かない。docs/USAGE.md には Zenzai の説明が無いので変更なし。
4. テスト `MacSettingsTests.Zenzai_Guidance_SaysBothSides_NoCherryPickedNumbers` (1331 → 1332 のうち、前は 1331 で全件通過 / 今回 1332): 既定 OFF、要約と「詳しく」に 得と損、共通の Description に Mac 固有の案内が無い、% の数字を出さない、「詳しく」に M4 Max・未確認・送りません。

## しなかったこと (意図)
- 既定値は OFF のまま。設定の新設・移行なし。初回起動のポップアップなど新しい画面なし。`src/Meltype/` (Windows UI) は触っていない。Windows の設定画面に出る文 (`Settings.cs` の Description) も変更前のまま。
- 「同音異義語に強くなる」とは言い切らず「同音異義語など、文脈で決まる語が合いやすくなる」と書く (測ったのは全体の精度で、同音異義語だけの数字ではない。査読 R2)。
- 画面に 82.5% などの数字は出さない (AJIMEE 200 件は選別した表で、利用者の文章の当たる率ではない)。

## 人の判断 (リョウさん)
- **決定 (2026-11-25 リョウさん「おすすめで対応して」): 「実験的」の表記は、M1 級の Mac で速さを確かめるまで残す。初回起動の案内など新しい画面は作らない。**
- **「実験的」を外すか**: 外さず残した (名前 `Zenzai (ニューラル変換、実験的)` のまま)。理由: 速さは M4 Max だけで、M1 級・メモリ逼迫時は未確認 (K67)。製品経路の p95 の目安 80 ms は測り直しが残っている。勧めるのと「実験的」は矛盾して見えるので、M1 級で確かめたあとに外すのがよい。外すなら `Settings.cs` の DisplayName・カタログの名前・README の 3 か所・`NativeCore.swift`/`Exports.cs` のコメントを合わせる (名前の変更は設定の保存名 `Zenzai` に影響しない)。
- **より強い案内** (初回起動のポップアップ、入力メニューでの提案) は、新しい画面になるので作っていない。
