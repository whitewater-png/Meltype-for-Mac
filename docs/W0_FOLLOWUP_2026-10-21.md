## 7. 入力ソースのアイコン (W2-5) — **18pt 化はしない (2026-10-22 決定)**

実機で見た結果 (DEVICE_CHECK の C1〜C4) が OK だったため、16pt のままにする。原版の用意も不要。以下は決定前の調査記録。

### 決定前の調査

| 項目 | 我々 (HEAD `42443be`) | 本家 (#942) |
| --- | --- | --- |
| 表現 | 16×16@72 + 32×32@144 = **16pt** | 18×18@72 + 36×36@144 = **18pt** |
| 墨の範囲 (2x) | `icon` 32×30/32 (余白ほぼ無し)、`icon-roman` 26×32 | 32×36/36 (左右 2px) |
| 色 | カラー (`TISIconIsTemplate=false`) | 黒 1 色テンプレート |
| 生成 | 手作業 (スクリプト無し) | `web/scripts/make-icons.mjs` (SVG から 18/36 を直接描画) |

- 18pt 化は **TIFF 2 ファイルの差し替えだけ**でできる (`Info.plist` は変更不要。論理サイズは dpi タグで決まる)。
- ただし**透過の原版が 32px ラスタしか無い** (`icon-1024.png` は不透明背景・別絵柄でメニューバーには使えない)。
- 案は 2 つ: (a) 墨を 18pt 枠いっぱいに拡大 (本家と同じ見かけ。32px からの拡大で甘くなる) / (b) 墨は現状のまま 36px の透明キャンバスに置く (シャープだが**大きくはならない**)。
- 最も良いのは、リョウさんから 1024px の透過原版 (M と A) をもらって 18/36 を直接描画すること。
- 生成は `tiffutil -extract` → `sips`/`ffmpeg` → `tiffutil -cat` で足りる (Pillow 不要。`-cathidpicheck` は dpi を壊すので使わない)。
