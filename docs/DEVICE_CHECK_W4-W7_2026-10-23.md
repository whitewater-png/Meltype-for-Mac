## A の症状と原因（推定）

- ON にして `こうせい` → Space → Tab を押しても、候補ウィンドウが **5 列の格子にならず横一列**のまま。
- Core は `view.grid == true` を返している（Core のテストは通っている）。
- Swift の `updateCandidates` は種別を変えるとき `setPanelType(...)` を呼ぶが、**その直後に `update()` / `show()` を呼んでいない**。Tab を押しただけでは候補一覧が変わらず window も可視なので、再表示の条件 (`view.candidates != candidateList || !window.isVisible()`) を通らず、**再レイアウトされないまま**横一列で出ている可能性が高い。
- 対策: 種別が変わったら hide → setPanelType → update → show で出し直す。`imk-trace.log` に `panel=grid count=N` を残して実機で確認する。
