## 要件定義書の候補
既存の要件 001〜011 (009・010・011 は PR #14・#15・#16)、10-24〜11-07 の文書の候補と突き合わせた。`eSIM`・`oAuth`・`ePub`・`Backspace`・`ifndef`・`pragma`・`endif` は過去の文書で `grep` して該当なし。候補 1 は要件 008 (`iCloud`・`iTunes`、辞書に 2 語で直した) と同じ形の広がり。

1. **母音 1 文字 + 大文字の英字 (`eSIM`・`oAuth`・`uEFI`) の頭がかなになる** — scope: core (語ごとに辞書で直すなら dictionary)
   - 背景: 本家 #1637 (`iGPU`)。fork では `iGPU` 単独は直っているが、`iGPUde` → `いGPUで`、`eSIM` → `えSIM`、`oAuth` → `おAuth`、`ePub` → `えPub`。要件 008 は 2 語を辞書に足したので、ほかの語は残っている。
   - minimum 要件: 小文字の母音 1 文字のすぐ後に大文字で始まる英字が続く形 (`eSIM`・`oAuth`・`iGPU`) を全体で英字のまま残す。後ろに助詞が続く形 (`iGPUde` → `iGPUで`) も英字の部分は崩さない。
   - 完成条件の案: 正解表に `eSIM`・`oAuth`・`ePub`・`iGPUde` (`iGPUで`) と守る行 (`ebi` → `えび`、`eki` → `えき`、`emoji` → `えもじ`、`iPhone`・`eBay`) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。大文字の扱いの判定に触るなら、査読員が境界例 (`aI`・`oK`・`iMac`・文頭の `I`) を作って base と比べる。全部小文字の `ebook` (`えbook`) を含めるかは人が決める。

2. **促音 `っ` の後で Backspace したら、元の子音に戻す (`ff` + BS + `uronto` → `ふろんと`)** — scope: core
   - 背景: 本家 #1636。fork でも `ff` + Backspace で `っ` が残り、続けて打つと `っうろんと` になる。打ち間違いを 1 文字消して直そうとした人は、`っ` まで消して打ち直すことになる。
   - minimum 要件: 子音を重ねて `っ` + 子音になった直後に Backspace を押したら、`っ` を元の子音 1 文字 (`f`) に戻し、次の文字と合わせて読み直す。音になった後の `っ` (`kitte` + BS → `きっ`) の今の値は変えない。
   - 完成条件の案: Core のテストに `ff\buronto` → `ふろんと`、`tt\bomato` → `とまと`、`kk\b` → `k` を足し、実装前は赤・実装後は緑。既存の `Backspace_DeletesOneKanaAtATime` (`kitte\b` → `きっ`、`ky\b` → `k`) と `Backspace_ThenRetype_RereadsRomaji` が通ったまま。Core 全件通過、eval-compare の broken 0。

3. **C/C++ のプリプロセッサの指令名 (`define`・`endif`・`ifndef`・`undef`・`pragma`) がかなに崩れる** — scope: dictionary (`define` が辞書にあるのに崩れる理由によっては core)
   - 背景: 本家 #1625 (辞書の提案)。fork では本家で英字の `define` → `でふぃね`・`endif` → `えんぢf` まで崩れる。`#define`・`#endif` を書く人が毎回直すことになる。
   - minimum 要件: `define`・`endif`・`ifndef`・`elifndef`・`undef`・`pragma` (`#` が前に付く形も) を英字のまま残す。`ima`・`unde`・`enda`・`ifu` のかなの語は今の値を変えない。
   - 完成条件の案: 正解表に `#define`・`#endif`・`#ifndef`・`#undef`・`#pragma`・`define`・`endif` と守る行 (`ima` → `いま`、`unde` → `うんで`、`enda` → `えんだ`、`ifu` → `いふ`、`dekiru`・`denwa` のような `de` 始まりの語) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。
