## 要件定義書の候補
既存の要件 001〜008 (009〜013 は PR #14〜#18)、10-24〜11-09 の文書の候補と突き合わせた。`alt`・`esc`・`pixiv`・`onvif`・`xattr` は過去の文書で `grep` して該当なし。`ゔぃ` は 11-01 の文書の `neovide` (辞書の候補) にだけ出る。

1. **キーの名前 `alt`・`esc`・`del`・`fn` がかなに崩れる (`alt` → `あっ`)** — scope: dictionary (表示と確定のずれまで直すなら core)
   - 背景: 本家 #1715 (本家 main では直っている)。fork では `alt` → `あっ`、`alt+tab` → `あっ＋たb`、`esc` → `えsc`、`del` → `でl`、`fn` → `fん`。ショートカットの説明を書くときに毎回崩れる。`altwoosu` は表示が英字のままなのに確定で `あっをおす` になる。
   - minimum 要件: `alt`・`esc`・`del`・`fn`・`tab` を単独でも、`+` や助詞 (`altwoosu` → `altをおす`) が続く形でも英字のまま確定する。`ato`・`atode`・`ese`・`deru`・`fune` などのかなは変えない。
   - 完成条件の案: 正解表に `alt`・`alt+tab`・`altwoosu`・`esc`・`del`・`fn` と守る行 (`ato` → `あと`、`alu` → `あぅ`、`deru` → `でる`、`esa` → `えさ`、`fune` → `ふね`) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。辞書に足すなら 002・005・007 と同じ形。`del` を英字にすると `delu` などの打ち方に響かないか、査読員が境界例を作って base と比べる。`tab`・`home` (`ほめ`)・`pgup` を含めるかは人が決める。

2. **`pixiv` がかなに崩れ、`pixiv` + 助詞は丸ごと英字のまま残る** — scope: dictionary
   - 背景: 本家 #1696 (本家 PR #1701 で閉じた)。fork では `pixiv` → `ぴぃv`、`pixivnitoukou` → `pixivnitoukou` (後ろの `にとうこう` までかなにならない)。絵の投稿の話で日常的に出る語。
   - minimum 要件: `pixiv` を英字のまま確定し、`pixivnitoukou` → `pixivにとうこう` になる。`pixi` (`ぴぃ`) など語でない形は今のまま。
   - 完成条件の案: 正解表に `pixiv`・`pixivnitoukou`・`pixivde` と守る行 (`pixi`・`pixel`・`booth`・`fanbox` の今の値) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。辞書に 1 語で `pixivnitoukou` まで直るかは試していない (**未確認**)。

3. **`onvif`・`vif`・`dvi` の `vi` がかなの `ゔぃ` になって英字と混ざる** — scope: core (語ごとなら dictionary)
   - 背景: 本家 #1711 (判定側で扱う設計の相談) と #1702。fork では `onvif` → `おんゔぃf`、`vif` → `ゔぃf`、`dvi` → `dゔぃ`。
   - minimum 要件: `v` を含む語で、かなと英字が 1 語の中で混ざる形 (`おんゔぃf`) にしない。`onvif`・`dvi` は英字のまま。`vi` を `ゔぃ` と読ませたい打ち方 (`vaiorin` などの今の値) は変えない。
   - 完成条件の案: 正解表に `onvif`・`vif`・`dvi` と守る行 (`vaiorin`・`viora` など `ゔ` を含むかなの今の値) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。本家は「語ごとの辞書では際限がない」として判定側の設計を相談中なので、語ごとに辞書で直すか、本家の設計を待つかは人が決める。
