## 要件定義書の候補
既存の要件 (main の 001〜049、開いている PR #40 の 050)、10-24〜11-25 の文書の候補、`eval/cases/` (`youtu.be`・`autoremove`・`#rrggbb` の行は無い。`youtube` は `upstream-quality.tsv` に `youtubewomiru` の 1 行だけ)、`docs/KNOWN_LIMITS.md` (該当なし) と突き合わせた。3 件とも、今の main と PR #40 の木の両方で崩れる。

1. **`youtu.be` のような短いドメイン (URL の中も) を英字のまま確定する** (本家 #2399) — scope: core
   - 背景: `youtu.be` が `ようつ。べ` になり、`https://youtu.be/abc` も `https://ようつ。べ/あbc` に崩れる。`https://example.com/abc` は崩れないので、`https://` の後ろでもホスト名の判定が `youtu` を日本語と読んでいる。
   - minimum 要件: `youtu.be` 単体と `https://youtu.be/…` を英字のまま確定する。`kyouhayoutubedemiru` などの日本語の文・`youtubewomiru` の今の形は変えない。
   - 完成条件の案: 正解表に `youtu.be`・`https://youtu.be/abc`・`youtu.bede` (直す行) と、近い日本語 (`youtsu`・`yotsuba` など、守る行) を足し、base で直す行が赤になることを確かめてから直す。Core 全件通過、eval-compare の broken 0、境界例の一括比較で損失 0。

2. **`#30b0e8` のような 16 進のカラーコードを英字のまま確定する** (本家 #2383。本家は PR #2392 で直した) — scope: core
   - 背景: `#` + 16 進 6 桁 (3 桁) の中の `e` や `ff` が `え`・`っf` になり、CSS・デザインの道具で色を打てない (`#e8e8e8` → `#え8え8え8`)。
   - minimum 要件: `#` に続く 16 進の 3 桁・6 桁 (と 8 桁) を英字のまま確定する。`#` の後ろの日本語 (ハッシュタグ `#にほんご` 系) の今の形は変えない。
   - 完成条件の案: 正解表に `#30b0e8`・`#ff00e8`・`#e8e8e8`・`#fff`・`color: #30b0e8;` (直す行) と、`#` + 日本語のハッシュタグ (守る行) を足し、先に赤を確かめてから直す。Core 全件通過、eval-compare の broken 0。本家の修正のコードは読まずに作る (読むなら GPL なので写してよいが、Mac 側で本家と比べる)。

3. **`autoremove`・`autosave` など `auto` + 英単語の複合語を英字のまま確定する** (本家 #2411) — scope: core または dictionary (どちらで直すかは調べてから)
   - 背景: `autoremove` が `あうとremove` になり、`sudo apt autoremove` のようなターミナルの命令が崩れる。`autosave`・`autostart`・`autoreload` も同じ。後ろの語 (`remove` など) だけが英語と判定され、頭の `auto` が日本語 (あうと) に割れる。
   - minimum 要件: `auto` + 辞書の英単語の形を、前後の判定 (語の頭・日本語の後ろ・空白の後ろ) にかかわらず英字のまま確定する。`autode` (あうとで) のような日本語の `auto` (アウト) の今の形が変わるなら、得失を書いて人が決める。
   - 完成条件の案: 正解表に `autoremove`・`sudo apt autoremove`・`autosave`・`autostart` (直す行) と、`autodatta`・`sore ha auto desu` などの日本語の `auto` (守る行) を足し、先に赤を確かめてから直す。Core 全件通過、eval-compare の broken 0、境界例の一括比較で日本語の損失 0。辞書で直すなら `check-dictionaries.mjs` が通り、隣のキーの打ち間違いの補正が崩れないこと (LESSONS の決まり) を確かめる。
