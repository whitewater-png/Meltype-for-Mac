## 要件定義書の候補
既存の要件 (main の 001〜055、開いている PR #42 の 051)、10-24〜11-26 の文書の候補、`eval/cases/` (`anb` のような行は無い。`@` の行は `@yksr_melt arigatou` と `@exampleabc-jh.ed.jpdesu`)、`docs/KNOWN_LIMITS.md` と突き合わせた。

1. **`ん` の後ろの子音 (b・m・h) が Enter の確定で消えるのを、表示どおりに確定する** (本家 #2461) — scope: core
   - 背景: 表示が `あんb` なのに Enter で `あん` が入る。打ち間違いの補正 (語末の余計なキーを消す) が、見えている文字を黙って消している。
   - minimum 要件: 表示に出ている語末の英字を、確定でも消さない (`anb` → `あんb`)。`yoroshikuy` のような補正を残すか外すか (本家は外す方針) は、得失を書いて人が決める。
   - 完成条件の案: 正解表に `anb`・`kanb`・`anm`・`anh`・`kyouhaanb` (直す行) と `anp`・`a-nb`・`honnda` などの守る行を足し、base で直す行が赤になることを確かめてから直す。Core 全件通過、eval-compare の broken 0、境界例の一括比較で日本語の損失を数えて人が見る。

2. **`@` の後ろで日本語の名前を打てるようにする (メンション)** (本家 #2463) — scope: core
   - 背景: LINE WORKS など、日本語の名前でメンションする道具で `@tanakasan` が英字のまま入り、`@田中` を打てない。`kyouha@tanakasanni` は前の日本語まで英字になる。
   - minimum 要件: 日本語の文の中の `@` + ローマ字を、日本語として読めるなら日本語にする道を作る (既定を変えるか、Shift+Space などの手で直すかは人が決める)。`@yksr_melt`・メールアドレス・`@exampleabc-jh.ed.jpdesu` の今の形は変えない。
   - 完成条件の案: 正解表に `kyouha@tanakasanni` (前の `kyouha` は日本語に、直す行) と、`@yksr_melt arigatou`・`foo@example.com`・`@user` (守る行) を足し、先に赤を確かめてから直す。Core 全件通過、eval-compare の broken 0。

3. **インストーラで入力ソースの一覧に書き込めなくても、途中で止まらず警告して続ける** (本家 #2448 から、fork でも起きるかを確かめる) — scope: swift (Mac の配布物。`mac/install.sh`)
   - 背景: 本家の Mac 版で、設定に書き込めない環境で更新が毎回失敗する。fork の `install.sh` も `set -e` の下で `defaults write` をするので、書き込めないとそこで止まり、後の起動し直しが飛ぶ見込み (コードを読んだだけ)。
   - minimum 要件: `defaults write` が失敗したら、警告と手で追加する手順を出して残りの手順を続ける。Meltype.app の入れ替えと署名の検査の流れは変えない。
   - 完成条件の案: `defaults` を失敗させる偽のコマンドで `install.sh` を流すテスト (Linux で動く形があれば) を足して、赤を確かめてから直す。Mac 実機で書き込めない状態を作れるかはチェックリストで人が確かめる。
