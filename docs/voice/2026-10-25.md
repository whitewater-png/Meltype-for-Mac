## 要件定義書の候補 (3 件まで)

### 1. ユーザー辞書の取り込みで、ファイル選択画面がクリックで消えないようにする
- 背景: 本家 #954 で、macOS 27.1.0 と 26.5.2 の両方で「macOS のユーザー辞書を取り込む」のファイル選択画面がクリックで消えて選べない (毎回)。このリポジトリにも同じ画面 (`NSOpenPanel`、`mac/Sources/MeltypeDictionary/UserDictionaryViewController.swift`・`TermDictionaryViewController.swift`) があり、起きるかは未確認。
- minimum 要件: macOS 26 以降で、取り込みのファイル選択画面からファイルを選んで取り込める。
- 完成条件の案: 実機チェックリスト (macOS 26.x・27.x で、取り込みボタン → ファイルを 1 回クリックして選ぶ → 取り込まれた件数が出る)。まず実機で再現するかを人が確かめる。
- scope: swift (実機でしか確かめられないので `CLAUDE.md` §5 の止める条件に当たる。人に渡す前提)

### 2. `mac` と打ったとき、`Mac` を変換候補に出す
- 背景: ブログで「`mac` の頭を大文字にしてくれない」。Core の `--repro mac` は `mac` で確定 (2026-10-25)。`propernouns.txt` には `iMac`・`MacBook` はあるが `Mac` が無い。
- minimum 要件: `mac` の英語の候補の一覧に `Mac` が出る (打ったままの `mac` で確定する既定は変えない)。
- 完成条件の案: Core のテストに「`mac` の候補に `Mac` がある」を足して赤 → 緑。`node tools/check-dictionaries.mjs` が通り、回帰ゲートの broken 0。
- scope: dictionary

### 3. 長文を確定せずに打ち続けると、途中から英字のままになる件の再現
- 背景: note の記事で、確定せずに長文を続けると途中からアルファベットのままになることがある。Core の `--repro` で日本語だけの 107 文字のローマ字を打っても、全部かなのまま (2026-10-25、偽の変換エンジン) で再現しなかった。
- minimum 要件: どのアプリで・何文字目あたりから起きるかを実機で特定し、Core で再現する打鍵があれば正解表に足す。
- 完成条件の案: 実機で再現した打鍵を `eval/cases/*.tsv` に足して外れることを確かめる (再現しなければ「再現せず」として閉じる)。直すのは別の要件にする。
- scope: core (実機で Swift 側の原因と分かれば swift)
