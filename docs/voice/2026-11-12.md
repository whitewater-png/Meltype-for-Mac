## 要件定義書の候補
既存の要件 001〜014、10-24〜11-11 の文書の候補と突き合わせた。`obsidian` は過去の文書と要件 013 にウィキリンクの話としてだけ出る (語そのものの崩れは無い)。`bugga`・`ぶっが`・`前後に半角スペース`・`ForgetLastCommit` は過去の文書で `grep` して該当なし。設定「英単語の前後に半角スペース」(`SpaceAroundEnglish`、`Settings.cs:192`) は既にあり、候補 3 は設定を足すのではなく、その設定の不具合の話。

1. **`obsidian` がかなに崩れ、`obsidianwo` は表示が英字なのに確定で `おんしぢあんを` になる** — scope: dictionary (表示と確定のずれまで直すなら core)
   - 背景: 本家 #1763。Obsidian を小文字で打つと崩れる。11-10 の `altwoosu` と同じく、変換ボックスでは英字に見えるのに確定でかなに変わる。`b` が確定で `ん` になる (`おbしぢあn` → `おんしぢあん`) のも表示と合わない。
   - minimum 要件: `obsidian` を単独でも、助詞が続く形 (`obsidianwo` → `obsidianを`、`obsidiande` → `obsidianで`) でも英字のまま確定する。`obake`・`obon`・`oboeru` などのかなの語は変えない。
   - 完成条件の案: 正解表に `obsidian`・`obsidianwo`・`obsidiande` と守る行 (`obake` → `おばけ`、`obon` → `おぼん`、`Obsidian` → `Obsidian`) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。辞書に足すなら 011・014 と同じ形。「表示は英字・確定はかな」のずれ (`obs` → 表示 `おbs`・確定 `おば` も) を別の要件にするかは人が決める。

2. **`bugga` (bug + が) が `ぶっが` になる** — scope: core (語の後ろで子音が重なる形の区切り方。辞書だけでは直らない見込み)
   - 背景: 本家 #1791。`bugwo` → `bugを`・`bugde` → `bugで` は通るのに、`ga` が続くと `g` が重なって促音 `っ` として読まれる。「bug が直らない」「bug があった」と打つ開発者には毎回起きる。`logga` も `ぉっが` になる (`--repro` で確かめた) ので、`g` で終わる英単語 + `が` に広く効く可能性がある。
   - minimum 要件: `bugga` → `bugが`、`bugganaoranai` → `bugがなおらない`、`buggaatta` → `bugがあった`。促音のかなの語 (`gakka` → `がっか`、`gakkou` → `がっこう`) は変えない。
   - 完成条件の案: 正解表に `bugga`・`bugganaoranai`・`buggaatta` と守る行 (`bugwo` → `bugを`、`bugde` → `bugで`、`gakka` → `がっか`、`gakkou` → `がっこう`) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。判定ロジックを変えるので、査読員が `g`・`k`・`t` で終わる英単語 + `が`・`か`・`た` の境界例 (`logga`・`dogga`・`blogga`・`packka`。どれも今の値は `logga` 以外試していない) を自分で作って base と比べる (CLAUDE.md §4)。

3. **設定「英単語の前後に半角スペース」で、消して打ち直すと先頭の英単語の前にスペースが入る (本家 #1757 と同じ作りか確かめる)** — scope: core
   - 背景: 本家 #1757 (本家の Mac プレビュー、macOS 27.2.1)。本家は「直前に確定した文字」の記録が Backspace などのあとも残るのを直した (PR #1756)。fork の `ForgetLastCommit()` も記録 (`_lastCommitText`・`_lastCommitEnglish`) を消さないので、同じことが起きると推測。
   - minimum 要件: 確定のあとアプリに渡したキー (Backspace・Enter・矢印) やクリックで記録を忘れ、入力欄が前の文字を返さないときは「前の文字は分からない」(打ち始めと同じ) として扱う。返すときはその文字を使う。
   - 完成条件の案: 先に Core のテストで「設定 ON・`githubnipushsuru` + Enter → Backspace を素通し → 前の文字を返さないホストで `githubnipushsuru` + Enter」が `github に push する` (先頭にスペース無し) になることを書き、今は赤 (先頭にスペースが入る) を確かめてから直す。前の文字を返すホストで `今日は` の後なら ` github` とスペースが入ることも守る。Core 全件通過、eval-compare の broken 0。Mac 実機 (TextEdit・ターミナル) で 1.5 秒以内に打ち直す形と、1.5 秒以上空ける形の両方を確かめる (**未確認**)。記録を消すと「直前の 1 語を F6/F10 で直す」(`R41-4`) や判定の文脈 (`PrecedingEnglish`) に響かないかを査読員が見る。
