## 要件定義書の候補
既存の要件 001〜014、10-24〜11-13 の文書の候補、`docs/KNOWN_LIMITS.md` と突き合わせた。`cve`・`linpeas`・`metasploit`・`nmap`・`repro` + 助詞・`share` + する は過去の文書で `grep` して該当なし (`repro` は bot の再現の話としてだけ出る)。候補 2 は 11-13 の候補 1 (`re-toga`、ハイフンの後ろ) と同じく頭の `re` の話だが、こちらはハイフンが無く、英単語の側が `repro`。候補 1 の「表示と確定のずれ」は 11-13 の候補 3 と重なるので、そちらに例を足す形でもよい。

1. **セキュリティの用語 (`cve`・`cwe`・`cvss`・`xss`・`nmap`・`metasploit`・`linpeas`) がかなに崩れる** — scope: dictionary (`nmapde`・`linpeas` の表示と確定のずれまで直すなら core)
   - 背景: 本家 #1908・#1902。脆弱性の番号や診断の道具の名前を小文字で打つと崩れる。`linpeas` は確定で末尾の `s` が消え、`nmapde` は表示が英字なのに確定で `んまおで` になる。
   - minimum 要件: 上の 7 語を単独でも、助詞が続く形 (`cvede`・`nmapde`・`metasploitde`・`linpeaswo`) でも英字のまま確定する。`ctf`・`csrf`・`sqli` は今のまま英字。かなの語 (`metai` → `めたい` など) は変えない。
   - 完成条件の案: 正解表に 7 語と助詞つきの形、守る行 (`metai` → `めたい`、`cvede` → `cveで`、`CVE` → `CVE`) を足し、実装前は外れ・実装後は当たる。Core 全件通過、eval-compare の broken 0。辞書に足すなら 011・012・014 と同じ形 (分野の辞書に入れるかは人が決める)。

2. **`re` で始まる英単語 + 助詞が `れ` + 英字に崩れる (`reprowo` → `れproを`)** — scope: core
   - 背景: 本家 #1901。`repro` 単独は英字のままだが、`wo`・`de`・`ga` が続くと頭の `re` だけがかなになる。開発者が「repro を書く」「repro で確かめる」と打つと毎回起きる。`rebasede` → `ればせで` も同じ頭の `re` の形。
   - minimum 要件: `reprowo` → `reproを`、`reprode` → `reproで`、`reproga` → `reproが` (`rebasede` → `rebaseで` まで含めるかは人が決める)。`rekisi`・`renraku`・`rei` などの `re` で始まるかなの語は変えない。
   - 完成条件の案: 正解表に `reprowo`・`reprode`・`reproga` と守る行 (`renrakuwo` → `れんらくを`、`reiga` → `れいが`) を足して赤 → 緑。判定ロジックを変えるので、査読員が `re` + 英単語 + 助詞 (`reviewwo`・`rebasede`・`releasega`・`resetwo`) と `re` + かなの語の境界例を自分で作って base と比べる (CLAUDE.md §4)。Core 全件通過、eval-compare の broken 0。

3. **`share` + する (`sharesuru`・`fairusharesite`) が `しゃれする` になる** — scope: core (`share` は既に同梱の英単語の一覧にあるので、辞書だけでは直らない見込み)
   - 背景: 本家 #1899 (本家は PR #1906 で「日本語の文の技術用語 + する を英単語にする」直しを入れようとしている)。`deploysuru` → `deployする` は通るのに、`share` は `しゃれ` (洒落) と読めるのでかなが勝つ。
   - minimum 要件: `sharesuru` → `shareする`、`sharesita` → `shareした`、`fairusharesite` → `ふぁいるshareして`。`syarenisuru`・`oshare` (`おしゃれ`) は変えない。
   - 完成条件の案: 正解表に上の 3 行と守る行 (`osharesuru` → `おしゃれする`、`syaredesu` → `しゃれです`) を足して赤 → 緑。判定ロジックを変えるので、`share` 以外の「かなとしても読める英単語 + する」の境界例を査読員が作って base と比べる。本家の直し (PR #1906) を取り込むか、fork で別に直すかは人が決める。Core 全件通過、eval-compare の broken 0。
