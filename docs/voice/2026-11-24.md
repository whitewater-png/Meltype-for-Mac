## 要件定義書の候補

1. **`vuln` が、表示は英字なのに Enter で `ゔおん` と確定する問題を直す** (本家 #2312。本家は main で直った) — scope: core (と、辞書で済むなら dictionary)

   - minimum 要件: `vuln`・`--script vuln`・`alma` を、表示どおり英字で確定する。`vu` で始まる かな (`vuittonn` など今の出力) と `vulns`・`vulnerable` の今の形は守る。辞書に語を足すか、表示と確定をそろえるかは調査で決める。本家の直し方は本家の main を Mac 側で見てから決める (GPL の本家なので取り込める)。
