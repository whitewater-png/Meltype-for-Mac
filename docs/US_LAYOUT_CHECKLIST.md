## JIS 配列 (案 A の影響確認)

| # | 操作 | 期待 | 結果 |
|---|---|---|---|
| J1 | 日本語入力中に ¥ キーを打つ | 何の文字が入るかを記録する (`¥` U+00A5 か `\` か) | |
| J2 | 日本語入力中に Option + ¥ を打つ | 何の文字が入るかを記録する | |
| J3 | 上の文字が、以前 (`￥`) と比べてどう変わったかを記録する | 半角の `\` か `¥` になる。全角の `￥` を期待していた人は、変換 (Space) で ￥ にできる | |

J1〜J3 の結果で、案 A のまま進めるかを決める。JIS で ¥ キーが `\` を返す環境があり、全角 ￥ が欲しい利用者がいる場合は、案 B (配列判別) か案 C (設定) を検討する。
