# W15: 設定「F9 / F10 の 1 回目は打ったまま」(本家 #515) — 2026-10-25

## 何をしたか

- 設定 `AlphanumericKeyStartsAsTyped` を足した (設定の「入力」グループ、既定 OFF)。
- **先に分かったこと**: Mac 版には、入力中の F9 / F10 を続けて押したときの大文字・小文字の切り替え (本家 #58 / #61) が **もともと無かった**。Mac 版の F10 は、何回押しても打ったままの英字 (`CompositionText.Display` が `Raw` を返すだけ)。このため本家の「1 回目を打ったままにする」だけを足しても動きが変わらない。
- そこで、ON のときだけ本家と同じ切り替えを足した: 1 回目は打ったまま → 2 回目 すべて大文字 → 3 回目 先頭だけ大文字 → 4 回目 打ったまま。見た目の変わらない段は飛ばす (`AI` → `Ai`)。F9 (全角) も同じ。F6〜F8 を挟むと 1 回目に戻る。
- **OFF のときは今までと完全に同じ** (何回押しても打ったまま)。説明文の「OFF のときは英字で見えている語の 1 回目で大文字」は本家 (Windows) の動きなので、Mac 用に「何回押しても打ったまま」に直した。
- 確定後の F10 / F6 (`TryToggleLastWord`) は触っていない。

## 変えたところ

- `CompositionText.cs`: `LetterCase` と `Case` を足し、`Mode` を変えると `Case` は打ったままに戻る。`Display` が F9 / F10 の表示に `Case` を掛ける。
- `CompositionController.cs`: `CompositionOptions.AlphanumericKeyStartsAsTyped`、ON のときの F9 / F10 は `SetAlphanumericMode`。
- `MeltypeSession.cs` / `Settings.cs` / `MacSettingsCatalog.cs`: 設定の配線 (`DoubleSpaceToJapanese` の直後)。
- テスト: `AsTypedTests.cs` 7 件 (既定 OFF・カタログ、OFF の不変、ON の 1 巡、かな表示から、F6 を挟む、F9 と AI、確定の文字)。`CompositionTests.Keyboard` に設定の項目を足した。
